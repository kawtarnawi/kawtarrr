# Portfolio — Kawtar Naoui Kheir

Portfolio inspiré de la maquette fournie.

## Fichiers
- `index.html` : structure du portfolio
- `style.css` : design responsive
- `script.js` : menu mobile

## Pour lancer
1. Décompresse le dossier.
2. Ouvre `index.html` dans Chrome.
3. Pour le développement, tu peux utiliser VS Code + Live Server.

## À personnaliser
- Remplace les liens LinkedIn/Behance.
- Remplace l'adresse email dans `index.html`.
- Si tu veux mettre ta vraie photo, remplace le bloc `.portrait` par une balise `<img>`.
- Ajoute les liens vers tes vrais projets dans les cartes.
